Deregister Nomad jobs that no longer have a Jenkins agent, for example because the controller was restarted while workers were running.

Only jobs whose ID looks like one this plugin generates are considered, and only after the Worker Startup Timeout has passed, so a worker that is still booting is left alone.

Give each controller its own worker template prefix if several Jenkins controllers share one Nomad cluster. Ownership is decided by the job ID, which starts with the template's Job Prefix: two controllers using the same prefix will each see the other's workers as orphans and deregister them, interrupting running builds.
